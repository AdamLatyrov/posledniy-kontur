# Как работать с «Последним контуром»

Эта папка — единый исходный проект мира. Основные материалы хранятся в обычных Markdown-файлах. Их можно редактировать в Obsidian, читать как красивую документацию через MkDocs Material или просматривать через Docusaurus.

Для обычного запуска можно просто дважды нажать файл `Открыть_книгу_мира.bat` в этой папке. Он поднимет оба локальных сайта и откроет их в браузере.

## Что считать источником истины

Редактировать нужно файлы в папках `Канон`, `Механики`, `Сезоны`, `Пак_лора`, `Реализация` и `Сообщество`.

Папки `Сайт_MkDocs` и `Сайт_Docusaurus` содержат только настройки и оболочки сайтов. Сгенерированные страницы не являются отдельными копиями лора.

## Obsidian

В LarbCorp уже есть основной Vault `AdamVault`:

`C:\Users\Adam\Documents\Work\LarbCorp\AdamVault`

Его не нужно заменять или дублировать. Для «Последнего контура» лучше использовать переключатель Vaults в Obsidian и открыть проект как отдельный рабочий Vault — так лор останется рядом с кодом, сайтами и материалами сборки, а общий AdamVault не будет засорён черновиками проекта.

В Obsidian выберите **Open folder as vault** и укажите эту папку:

`C:\Users\Adam\Documents\Work\LarbCorp\Products\Майнкрафт_Последний_контур`

Obsidian будет показывать Markdown-файлы, ссылки между ними и карту материалов. Это основной режим редактирования.

## MkDocs Material

Откройте PowerShell в этой папке и выполните:

```powershell
& 'C:\Users\Adam\AppData\Roaming\Python\Python312\Scripts\mkdocs.exe' serve -f 'Сайт_MkDocs\mkdocs.yml'
```

Затем откройте `http://127.0.0.1:8000`.

Для разовой сборки статического сайта:

```powershell
& 'C:\Users\Adam\AppData\Roaming\Python\Python312\Scripts\mkdocs.exe' build -f 'Сайт_MkDocs\mkdocs.yml' --clean
```

Результат появится в `Products\Сайт_Последний_контур_MkDocs`.

## Docusaurus

Откройте PowerShell в папке `Сайт_Docusaurus` и выполните:

```powershell
$env:Path='..\Инструменты\node-v24.17.0-win-x64;' + $env:Path
npm.cmd run start -- --host 127.0.0.1
```

Затем откройте `http://127.0.0.1:3001`.

Для production-сборки:

```powershell
$env:Path='..\Инструменты\node-v24.17.0-win-x64;' + $env:Path
npm.cmd run build
```

Готовый сайт появится в `Сайт_Docusaurus\build`.

## Какой режим выбрать

- Obsidian — писать, связывать заметки и постепенно прорабатывать лор.
- MkDocs Material — быстро читать всю книгу мира с поиском и оглавлением.
- Docusaurus — развивать публичную энциклопедию, форумную документацию или будущий сайт проекта.

Лучше всего сохранять материалы в Markdown и не редактировать сгенерированные папки `build` или `Сайт_Последний_контур_MkDocs`.
