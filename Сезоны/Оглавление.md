# Сезонные документы

Каждый сезон должен содержать:

- входное состояние мира;
- основную тему;
- новые механики;
- ключевые локации;
- фракции;
- акты;
- варианты финала;
- карточку последствий для следующего сезона.

Подробно прорабатывается только ближайший сезон. Остальные документы задают направление и ограничения, но не закрывают будущие решения игроков.
