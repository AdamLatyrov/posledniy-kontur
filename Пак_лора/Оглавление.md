# Lore-pack

## Назначение

Lore-pack — это материалы, которые видят игроки. Он не должен раскрывать администраторские секреты из библии мира.

## Состав

- стартовые контракты;
- книги и журналы;
- радиосообщения;
- терминалы;
- задания поселений;
- описания предметов;
- секретные досье игроков;
- финальные протоколы;
- материалы для публичного devlog.

## Версионирование

```text
Lore-pack S01 v0.1
Lore-pack S01 v0.2
Lore-pack S02 v1.0
```

Игрокоориентированные материалы не должны требовать чтения всей библии мира.
